# CETI Integrated

Standalone monorepo for organizing Project CETI as an AI and data platform.

This repository is intended to preserve the history of existing Project CETI repositories under `sources/`, while new project-level code lives in `packages/`, `pipelines/`, `datasets/`, `experiments/`, and `docs/`.

See [docs/superpowers/specs/2026-05-26-project-ceti-monorepo-design.md](docs/superpowers/specs/2026-05-26-project-ceti-monorepo-design.md) for the initial architecture design.
